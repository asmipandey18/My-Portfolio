# Personal Portfolio

A modern, responsive personal portfolio website built with **HTML5, CSS3, and Vanilla JavaScript** to showcase my skills, projects, and professional journey.

## Features

- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Semantic HTML** – Structured with clean and meaningful markup.
- **Dark Theme** – Modern and visually appealing interface.
- **Accessibility** – Designed with usability and accessibility in mind.
- **Fast Performance** – Lightweight and optimized for a smooth browsing experience.
- **Interactive UI** – Enhanced with JavaScript functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
